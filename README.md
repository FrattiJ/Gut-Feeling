# Gut Feeling

A single-file, privacy-first IBS food & symptom tracker that runs entirely in the browser with no server, no account, and no data leaving your device.

## Features

- **Meal logging** — 4-step form capturing meal name, time, type, and source (homemade / restaurant / packaged)
- **Symptom tracking** — discomfort scale (0–10), symptom chips, and onset timing
- **Trigger tagging** — common IBS trigger categories: dairy, gluten, high-FODMAP, fat/spice, and more
- **Today's feed** — quick view of the day's meals with symptom indicators
- **History** — searchable, filterable meal log with severity color-coding
- **Insights** — trigger–symptom correlation analysis to spot patterns over time
- **Edit / delete** — update symptoms or full meal details after the fact

## Usage

Open `index.html` directly in any modern browser — no install, no build step.

All data is stored in `localStorage` in the browser where you opened the file. Clearing browser data will erase your logs.

## Privacy

No data is ever sent anywhere. Everything lives in your browser's localStorage.
